state space X, smooth energy, reversible weighted-divergence generator
with THE invariant probability rho - wellposedness/core/uniqueness by
the named standard family), a declared domain family {D_a} with typed
nonvacuity rows, and certificates for the following rows.

```text

   locally constant on an open full-measure subset of X.
R2 EQUILIBRIUM NON-TRIVIALITY: rho(ell = v) > 0 for at least two
   distinct values v.
R3 PERSISTENCE: for each typed domain D_a and every q in D_a there is
   an explicit r(q) > 0 with, for every delta > 0,
   P_q( ell(theta_t) constant on [0, exp(beta (r(q) - delta))] ) -> 1
   as beta -> infinity.

   sets, on the SAME process, with a
   certified decorrelation |E_q[F(theta_t)] - int F drho| <= C e^{-c t}
   at a beta-POLYNOMIAL timescale (c of order 1/beta at worst), from
   every starting point.

   parameter b, each member preserving wellposedness and possessing THE
   invariant probability of its own pair, with the passive and
```
