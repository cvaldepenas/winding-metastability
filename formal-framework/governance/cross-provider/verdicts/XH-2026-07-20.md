### T2, Condition (A), and the T1 Lean pair

Fix `N >= 3`, `kappa > 0`, the reversible diffusion generated by
`beta^-1 Delta - grad J . grad`, and then let `beta -> infinity`. For the
constants component `A` of `{J < 2 kappa}`, SR-T2 is an expectation statement
about `tau_exit(A)`, while T2 transfers it pathwise to
`tau_exit(Sigma_0)`. The corrected X4 pin is not a generic no-bottom theorem:
it uses the one-compactum Condition (A) route (compact ground circle, no
outside zero-quasipotential equivalence, closure attraction/omega-limit
capture, compact closure, and regular boundary). It supplies the stronger
ground exponent `2 kappa-m_0=2 kappa`, which implies the displayed weaker
`2 kappa-J(q)` bound for each fixed `q in A`.

The compiled Lean signatures say exactly:

- `J_ge_two_kappa_on_Delta`: for a nonempty finite configuration index,
  `kappa>0`, and `theta in Delta`, `2 kappa <= J(theta)`. It does not need
  `N>=3`.
- `path_meets_Delta`: for `N>=3`, a path `gamma : R -> Config N` continuous
  on all of `R`, ordered endpoints `t0<=t1`, start in `Sigma0`, and an endpoint
  off `Delta` with nonzero winding, some `t in [t0,t1]` lies in `Delta`.

These are deterministic path statements. The almost-sure diffusion-exit
wrapper remains prose/external, as `lean/README.md` itself records.

### SH.4 and the common Display-2 stopping object

SH's working family fixes a smooth `E`, `cap`, and a connected component
`D` of `{E<cap}` containing the compact ground orbit `G`, with (F1)-(F4).
It defines

`D_eta = {E <= cap-eta} intersect closure(D)`

and `tau_D` as exit from `D`. SH.4 states, for every fixed `eta>0` and
`q in D_eta`,

`limsup_{beta->infinity} beta^-1 log E_q[tau_D] <= cap-e_0`.

For the passive row, `E=J`, `cap=2 kappa`, `D=A`, `G=C_k`, and `e_0=m_k`
(`m_0=0`). Thus the lower and upper bounds can govern exactly the same
`tau_A`. Because a connected component of the open sublevel is relatively
closed in that sublevel and paths are continuous, its first exit is its first
reach of the cap level. This validates the master display's line 43-44
stopping-time claim, but only after `A_eta` is defined as the SH set above.

The distinct label stopping time dominates `tau_A`; it is not equal to it.
SH.6 lines 657-665 and the SH Honest Boundary lines 668-688 explicitly say
that exit at the cap need not change sector and that the matching label upper
bound is typed open.

### LP.3, LP.5, and campaign #22

For the coupled `W*` member, flagship `k=1`, `N>=10`, M2-PIN and all LP
smallness rows fixed, LP.3 states for nonnegative `eps<eps_2` and fixed
`q in D_k(eps)`:

`liminf_{beta->infinity} beta^-1 log E_q[tau_change^theta]
 >= S_k-m_k-eps*w_k-C_inv*eps^2`,

where `w_k=W*(G_k)=m_k/kappa` is the **ground** coupling value. LP.5, only
for `0<eps<eps_2`, adds the conditional expectation upper bound

`limsup <= S_k-m_k+eps*(S_k/kappa-w_k)+C*eps^2`.

scoped to the `w_phi=0` stratum and the coefficient `S_k/kappa` is typed to

`kappa` normalization is the **saddle** level shift. It is not LP.3's
ground coefficient `w_k`.

   83-86).** The source proves a two-sided law for `tau_A=tau_D`; the master
   calls `exp(beta(2 kappa-m_1))` the label-flip scale and says the label
   "flips" on it, sharp and two-sided. SH explicitly blocks that inference:
   label change/hitting `Delta` occurs no earlier than domain exit, while
   exiting at `{J=2 kappa}` need not change the label. **Downstream:** H3 and
   the Master Theorem's Part III cannot close with the claimed flagship flip
   scale. The valid replacement is "sublevel-component exit scale"; label
   sharpness remains open.

2. **BLOCKING -- LP.5 has a second unresolved bridge (`lane-master`, lines
   62-63 and 75; `lane-lp`, lines 779, 804, and 817).** The master says the
   two-sided coupled window is modulo only `PROD-EXCURSION`. The standing
   LP.5 proof still invokes the former global `SH.2'` ground minorization in

   lane-SH source. The July-20 migration text moves SH.3 Step 4 and SH.4's
   along-ground chain to L1'/L2; no LP.5 migration is present. X5 already
   identified this exact residual. **Downstream:** the LP.5 upper side is at
   least conditional on `PROD-EXCURSION` **and** a source-conformed local
   minorization/renewal migration. Display 3's proved lower side is not
   affected by this finding.

   contradictory (`lane-master`, lines 41-42 and 89).** The newest lane-SH
